# Импорт данных

## Какие файлы можно загрузить
Существующие данные можно импортировать в VoroniX из файлов Excel, CSV, Word и обычных текстовых файлов. Базу клиентов не нужно переносить вручную.
Ключевые слова: импорт, загрузить, перенести, excel, csv, word, txt, файл, формат, таблица, import, upload, migrate, file, format, spreadsheet, жүктеу, файл, формат

## Если нужного формата нет в списке
Если данные хранятся в другом формате или в другой системе, способ переноса уточняет команда VoroniX.
Ключевые слова: другой формат, другая crm, перенос, миграция, migration, other format, көшіру
