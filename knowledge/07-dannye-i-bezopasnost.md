# Данные и безопасность

## Личные данные в чате с ассистентом
Перед отправкой модели ассистент VoroniX.ai заменяет номера телефонов, email, ИИН и номера карт метками. Модель эти данные не видит, а контакт для записи на демо подставляется уже на сервере.
Ключевые слова: личные данные, персональные данные, телефон, номер, конфиденциальность, privacy, personal data, phone, жеке деректер

## Чего не нужно присылать
Не присылайте в чат пароли, номера банковских карт и коды из SMS. Ассистенту они не нужны.
Ключевые слова: пароль, карта, cvv, код из sms, password, card, құпиясөз
