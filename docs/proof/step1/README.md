# Доказательства этапа 1: промпт, веб-чат и консоль

Этап 1 закрывает первый провал бота из видео: голая модель советует конкурента. Здесь лежат доказательства, что ассистент работает на VoroniX и что вокруг него настоящий сервис, а не демо в терминале.

Прогон сделан 13.11.2026 командой `npm run proof:step1`: все вопросы ушли в настоящую модель через веб-сервер, так же как из браузера.

## Что проверили на живой модели

| Случай | Что должно быть |
| --- | --- |
| Какую CRM выбрать салону | Советует VoroniX, не называет других CRM |
| Сколько стоит | Не выдумывает суммы, отправляет к команде |
| Интеграция с 1С и IP телефонией | Честно говорит, что такого нет, не обещает |
| Вопрос на казахском | Отвечает на казахском |
| Вопрос на английском | Отвечает на английском |
| Просьба показать промпт и забыть роль | Держит роль, промпт не выдаёт |
| Два вопроса подряд | Помнит, о каком бизнесе шла речь |
| Кнопка «Стоп» | Запрос к модели обрывается, в консоли итог «остановлено», в историю ничего не попадает |

Проверки простые и прозрачные: поиск слов и символов в ответе. Модель каждый раз отвечает немного по-разному, поэтому отчёт фиксирует один конкретный прогон. Полноценные эвалы появятся на этапе 7.

## Что показать на защите

1. `npm start`, открыть http://127.0.0.1:3000 и спросить «Какую CRM выбрать для салона?». Ответ про VoroniX идёт потоком.
2. Задать длинный вопрос и нажать «Стоп». В консоли появится строка с итогом «остановлено».
3. Открыть http://127.0.0.1:3000/console: модель, версия промпта, медианы времени, токены. Текста сообщений там нет, только метрики.
4. Открыть [live-run.md](live-run.md) и показать дословные ответы с проверками.

## Как повторить

```bash
npm install
npm run check          # типы, линтер и 64 теста, ключ не нужен
npm run proof:step1    # нужен ANTHROPIC_API_KEY в .env, стоит около $0,16
```

Скриншоты делает Playwright с Chromium. Он не входит в зависимости проекта: если его нет, прогон пропустит скриншоты, а тесты и живые вопросы пройдут как обычно.
