# VoroniX.ai

ИИ-ассистент поддержки и продаж для CRM VoroniX. Он отвечает тем, кто выбирает VoroniX или уже работает в ней: что умеет продукт, как он ляжет на процессы конкретной компании, что делать дальше.

Под капотом готовая модель Claude через API Anthropic. Но один ключ API ещё не делает ИИ своим, поэтому проект собирается по шагам, и каждый шаг добавляет ассистенту новый слой.

Автор: Altynbekov Yernazar

## Шаг 1: системный промпт

Без системного промпта модель не знает, на кого работает. На вопрос «какую CRM выбрать?» она честно советует конкурентов, а о VoroniX ничего не знает. Системный промпт это инструкция, которую модель получает перед каждым ответом.

Что сделано:

- `prompts/system/v1.md`: системный промпт с версией. Разделы: кто ассистент и на кого работает, факты о продукте, голос бренда, о чём говорит и о чём нет, конкуренты, честность, язык ответа (RU, KZ, EN), формат ответа, удержание роли.
- `config/product.json`: факты о продукте (функции, каналы, цены, конкуренты, сайт). В тексте промпта их нет, они подставляются из конфига. Это единственный источник правды для ассистента: перед запуском для клиентов команда проверяет каждую строку.
- `config/assistant.json`: модель, усилие, лимит ответа, версия промпта.
- Сборка промпта строгая: если переменной не хватает или осталась лишняя, программа падает, а не отправляет в модель недособранный текст. У каждого собранного промпта есть отпечаток (первые 12 символов SHA-256), по нему видно, какая именно версия ушла в модель.
- Чат в терминале со стримингом ответа.
- Демонстрация «до и после»: 6 одинаковых вопросов к модели без промпта и к ассистенту с промптом. Результат: [docs/demo/step1-before-after.md](docs/demo/step1-before-after.md).
- Юнит-тесты сборки промпта, конфигов и запроса к API, проверка типов, линтер, CI на каждый PR.

### Веб-чат и консоль сотрудника

- Свой веб-сервер без лишних зависимостей. Ответ приходит в браузер потоком (SSE), диалог помнится по cookie сессии.
- Защита страницы: строгий CSP без inline-скриптов, запрет встраивания во фреймы, проверка Origin и JSON у запросов, лимит сообщений с одного адреса, общий лимит одновременных ответов, один ответ за раз в диалоге.
- Кнопка «Стоп» и закрытая вкладка обрывают запрос к модели, оборванный ответ не сохраняется.
- Без ключа API страница открывается и честно говорит, что ассистент не подключён.
- Консоль сотрудника `/console`: модель, промпт, слои, медианы времени, токены, последние ответы с id запроса. Текст сообщений не хранится, только метрики. Пока консоль открывается только с этого компьютера, вход по ролям появится на этапе 4.
- Доказательства этапа: [docs/proof/step1](docs/proof/step1/README.md), 28 из 28 проверок на живой модели и 64 из 64 тестов.

### Выбор модели

Модель: `claude-opus-5-5` (Claude Opus 5.5), усилие `medium`.

- Это текущая модель линейки Opus. В документации Anthropic прямо сказано: если не уверены, какую модель выбрать, начинайте с Claude Opus 5.5 для большинства задач ([models overview](https://platform.claude.com/docs/en/about-claude/models/overview), проверено 12.11.2026). Ассистент отвечает от имени компании, поэтому важнее всего точно следовать длинной инструкции, не выдумывать факты и уверенно отвечать на казахском. Это сильная сторона старших моделей.
- Цена по прайсу Anthropic: 4 доллара за 1 млн входных токенов и 20 долларов за 1 млн выходных ([pricing](https://platform.claude.com/docs/en/about-claude/pricing), проверено 12.11.2026). Весь прогон демонстрации (12 запросов) занял 11 834 входных и 7 330 выходных токенов, это около 0,19 доллара.
- Усилие `medium` у этой модели значение по умолчанию; мы задаём его явно, чтобы поведение не менялось молча. Для чата этого достаточно.
- Включён серверный повтор при отказе (`fallbacks: "default"`): если модель откажет по политике безопасности, Anthropic сам повторит запрос на запасной модели. Выключается полем `refusalFallback` в `config/assistant.json`.
- Модель и усилие меняются без правки кода: в конфиге или переменными `VORONIX_MODEL` и `VORONIX_EFFORT`. Дешёвые модели для простых вопросов появятся на шаге 6 (роутер моделей).

## Запуск

Нужен Node.js 22.18 или новее: он запускает TypeScript напрямую, без сборки.

```bash
npm install
cp .env.example .env      # вставьте свой ANTHROPIC_API_KEY, файл .env в git не попадает
npm start                 # веб-чат на http://127.0.0.1:3000, консоль сотрудника на /console
npm run chat              # чат с ассистентом VoroniX.ai в терминале
npm run chat -- --raw     # та же модель без системного промпта, для сравнения
npm run demo:step1        # прогон 6 вопросов «до и после», отчёт в docs/demo
npm run prompt:show       # посмотреть собранный системный промпт
npm run check             # типы, линтер и тесты (ключ не нужен)
npm run proof:step1       # доказательства этапа 1: тесты, живые вопросы, скриншоты
```

Команды в чате: `/reset` начать заново, `/info` модель и версия промпта, `/exit` выход.

```
docs/demo/           сохранённые результаты демонстраций

```

## Безопасность ключа

Ключ API читается только из переменной окружения `ANTHROPIC_API_KEY` (или из локального файла `.env`, который игнорируется git). В коде, конфигах, тестах и CI ключа нет: тесты работают без сети.
